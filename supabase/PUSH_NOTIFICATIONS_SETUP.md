# إعداد إشعارات الجهاز والموقع مغلق

الإشعار داخل جرس الموقع وحده لا يظهر بعد إغلاق الصفحة. لإرسال تنبيهات الجهاز في الخلفية، نفّذ الخطوات التالية مرة واحدة، وبعدها كل عضو يفعّل الإشعارات من جهازه.

## 1. حدّث جداول Supabase

افتح **SQL Editor** في مشروع Supabase، ثم انسخ محتوى [notifications.sql](notifications.sql) كاملًا واضغط **Run**. السكربت قابل لإعادة التشغيل، ويضيف أيضًا جدول اشتراكات الأجهزة ويصلح إشعار المسؤول الذي أنشأ المهمة.

## 2. أنشئ مفاتيح Web Push

على جهازك شغّل هذا الأمر في PowerShell أو Terminal، ثم احتفظ بالناتج محليًا:

```text
npx --yes --package=web-push@3.6.7 web-push generate-vapid-keys --json
```

سيظهر مفتاحان باسم `publicKey` و`privateKey`. لا ترفع المفتاح الخاص إلى GitHub ولا ترسله في محادثة أو تضعه في `index.html`.

## 3. أضف أسرار الإرسال في Supabase

من لوحة المشروع افتح **Edge Functions > Secrets** وأضف:

| الاسم | القيمة |
| --- | --- |
| `VAPID_PUBLIC_KEY` | قيمة `publicKey` التي ظهرت في الخطوة السابقة |
| `VAPID_PRIVATE_KEY` | قيمة `privateKey` التي ظهرت في الخطوة السابقة |
| `VAPID_SUBJECT` | `https://bebomaher2468.github.io/mahmotna/` |

مفتاح Supabase السري يقرأه الخادم من بيئة Edge Functions تلقائيًا؛ لا تضفه إلى الموقع أو GitHub.

## 4. انشر وظيفة الإرسال

ثبّت Supabase CLI إذا لم يكن موجودًا، ثم من مجلد المشروع شغّل:

```text
supabase login
supabase link --project-ref gxoddlgmxgkojfloxpon
supabase functions deploy send-push
```

ملف الوظيفة موجود في `supabase/functions/send-push/index.ts`. لا تجعل التحقق من تسجيل الدخول معطّلًا؛ الوظيفة تستقبل طلبات من مستخدم مسجّل فقط، وتتحقق من دور المسؤول قبل إرسال إشعارات المهام ومراجعة التسليمات.

## 5. فعّل الإشعارات على كل جهاز

بعد نشر الموقع والوظيفة، سجّل دخولك، وافتح جرس الإشعارات، واضغط **تفعيل على الجهاز** ثم اسمح للمتصفح بعرض الإشعارات. استخدم **إرسال إشعار تجريبي** للتأكد. كرر التفعيل على كل متصفح أو جهاز تريد وصول التنبيهات إليه.

بعد التفعيل، وصول الإشعارات لا يحتاج أن تكون صفحة الموقع مفتوحة. قد يمنعها نظام التشغيل إذا عطّلت إشعارات المتصفح أو منعت تشغيله في الخلفية. إذا سبق واخترت «حظر»، غيّر إذن الإشعارات من إعدادات الموقع في المتصفح أولًا.

## ماذا يرسل الموقع؟

- عند إضافة مهمة: يصل إشعار للأعضاء وللمسؤول الذي أنشأها.
- عند قبول التسليم أو طلب تعديله: يصل إشعار للعضو صاحب التسليم.
- التنبيهات تعتمد على إذن المتصفح والاتصال بخدمة Push. جهاز لا يملك اشتراكًا لن تصله إشعارات الجهاز، لكنه يظل قادرًا على مشاهدة الإشعار داخل الموقع.
